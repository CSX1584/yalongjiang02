# 雅砻江三方向视觉 Demo · V2

三种独立页面构成，每种均包含 3D 流域地图、故障诊断、关单核查。

| 方向 | 地图 | 故障诊断 | 关单核查 |
| --- | --- | --- | --- |
| 精密工业 | 顶部仪表、左侧地形、右侧电站台账 | 大幅设备剖面、右侧判断、底部趋势 | 横向工程报告、前后对照表、页尾核查 |
| 清晰轻盈 | 待办入口、地图、横向站点卡 | 趋势证据在左、设备定位在右、底部处理步骤 | 左侧经过、中间复测记录、右侧核查 |
| 沉浸空间 | 全幅场景、站点索引、底部状态台 | 中央设备、左侧读数、右侧可展开证据 | 左侧恢复结果、右侧核查操作 |

## 本地运行

需要 Node.js。首次从仓库下载后：

```sh
npm ci
npm run dev
```

对比九个页面：http://127.0.0.1:5273/compare.html 。

交互入口：http://127.0.0.1:5273/ 。本机安装依赖后也可双击 `启动预览.command`。3D 模块需要 HTTP 服务，不能直接用 file:// 打开 HTML。

- `?style=precision&page=map`：精密工业
- `?style=light&page=map`：清晰轻盈
- `?style=immersive&page=map`：沉浸空间
- `page` 可切换为 `diagnosis`、`review`

## 参考的具体落点

- SSTR、Brikken：工业版以细分隔、工程编号、读数与基线对照组织内容。
- Tabella、Virya：轻盈版保持稳定横向导航，以待办、证据、核查形成工作路径。
- ON、Sobha：沉浸版让场景占据主体，站点选择带动镜头推进，操作集中在边缘。
- Zetta、ForAI：统一环境光与接触阴影，展示剖面、绕组、管路、法兰及紧固件。

## 3D 与交互

地形使用原项目局部高程数据重采样为 256 × 256 高度场，在约 8.5 万顶点地表上重构示意河道及站区。站区包括弧形坝体、溢流结构、厂房、通风设备、升压站及旋转风机。点击电站会推进到站区，恢复视角返回流域。

水轮发电机模型包含蜗壳、曲面转轮叶片、主轴、叠片转子、24 组铜绕组、定子外壳、上导轴承、冷却管路、阀门、法兰与螺栓。支持结构展开、部件选择和旋转查看，金属材质使用环境反射。

温度/振动切换、趋势悬浮读数、检修/复测记录、三项核查、退回复核、重新提交、关单和归档均可操作。关单后地图解除告警；刷新恢复初始状态。

所有业务数据为演示数据。地形为基于高程重构的流域示意，不是电站实际 GIS 布局；设备为程序建立的结构示意，不是厂商 CAD。滤网图片为结构示意。无生产系统连接。

## 版本与验证

- `main` 与 `archive-v1-20261023`：布局、模型精修前的初版。
- `refine/layout-and-3d-v2`：本次布局及 3D 精修。
- `artifacts/`：初版九页预览及当时验证结果。
- `artifacts-v2/`：新版九页预览、站区近景、结构展开及浏览器验证记录。

代码入口：`app.js` 管理状态和操作，`views.js` 定义三套页面结构，`scene.js` 建立三维场景，`style.css` 定义视觉与窄屏适配。
