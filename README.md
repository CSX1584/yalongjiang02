## V6 演示方法

进入首页任务，查看 AI 依据、结构定位与处置方案。每次确认后，按“切换并接续”交给下一责任人。角色不会自动代替审批。

故障确认 → 工单复核与派单 → 工作票提交 → 工作票审批 → 操作票提交 → 操作票审批 → **现场执行** → 工单结案 → 知识沉淀。

- 左侧回看已完成环节的只读快照；未来环节锁定。
- 可修改人员、时间、工序、操作项、现场记录、复测数值及处置经验。
- 支持现场复核、暂缓、退回、不许可和补充复测；这些动作不标记正常完成。
- 当前浏览器保存进度；“处理记录”可导出 JSON，“重置演示”从头开始。
- 精密工业场景无悬停激光。地图与设备直接切换；设备内部局部定位使用缓动，其余结构淡化。
- 图表按实际容器尺寸重绘，支持指针和方向键读数。

本版使用本地演示数据、规则校验与预置 AI 材料，未连接模型服务、生产设备或真实两票系统。3D 为结构与资产分区示意；阈值、容量和工况不作为实际运行依据。

# V5 历史视觉方案

三种独立页面构成，每种均包含 3D 流域地图、故障诊断、关单核查。

| 方向 | 地图 | 故障诊断 | 关单核查 |
| --- | --- | --- | --- |
| 精密工业 | 平面总图、电站白模、悬浮球与台账 | 整高解剖/线框、局部定位、侧边证据 | 横向工程报告、前后对照表、页尾核查 |
| 清晰轻盈 | 待办入口、地图、横向站点卡 | 趋势证据在左、设备定位在右、底部处理步骤 | 左侧经过、中间复测记录、右侧核查 |
| 沉浸空间 | 全幅场景、站点索引、底部状态台 | 中央设备、左侧读数、右侧可展开证据 | 横向恢复结果、宽幅趋势、右侧核查与记录 |

## 本地运行

需要 Node.js。首次从仓库下载后：

```sh
npm ci
npm run dev
```

对比九个页面：http://127.0.0.1:5273/compare.html 。

交互入口：http://127.0.0.1:5273/ 。本机也可双击 `启动预览.command`，它为当前目录分配独立端口，避免历史版本误打开新版。3D 模块需要 HTTP 服务，不能直接用 file:// 打开 HTML。

- `?style=precision&page=map`：精密工业
- `?style=light&page=map`：清晰轻盈

- `page` 可切换为 `diagnosis`、`review`

## V5 更新

- 精密工业仍以浅色为主：浅灰绘图面、深灰结构线、白模与柔和投影；故障部件及趋势保留橙色。
- 精密工业的设备页改为独立的剖面结构模型。可切换“解剖 / 线框”，查看轴承瓦块、定转子、转轮和冷却水滤网的内部结构；支持纵向展开。
- 点击温升告警、流量/压差读数、底部部件按钮或场景标注，平滑聚焦到对应部件。选中部件保留橙色，其余结构退为淡线框。“整机”返回全貌。
- 模型占据左侧完整工作高度，趋势证据置于右侧。低高度窗口的诊断侧栏独立滚动；窄窗口按模型、异常、处理、趋势顺序展开。
- 精密工业移除悬停扫描、激光与空闲悬浮。地图和设备直接切页，场景内定位使用缓动。
- 精密工业首页采用平面分区、河道和道路刻线、精细白模、低角度投影、浮球站点与简短站名。点击站点可放大到站区。
- 另外两套方案的场景与布局保持各自的展示方式。

## V4 历史更新

- 沉浸空间改为浅色：暖白底、白色浮层、柔和接触阴影，功能和图表保留青绿色。
- 沉浸版核查页铺满可用宽度，结果与温度读数横排，趋势图横向展开，核查和作业记录独立置于右侧。窄窗口顺序排布，低高度窗口的核查列可以滚动。
- 首页/地图与设备详情直接切换，取消跨页面的飞行和画布拉伸。场景内的站点、部件聚焦和结构展开继续使用缓动。
- 精密工业使用正交投影、地形网格、设备基准网格、径向刻度、外轮廓、方形底座和图框索引。设备保持稳定，不做空闲悬浮；布局以紧凑的工程读数、分隔线和台账组织。
- 沉浸空间使用透视投影、圆形底座、柔光与轻微悬浮，操作放在场景边缘。两种方向共用设备结构，展示方式独立。

## V3 历史更新

- 黑白灰作为基础，白色卡片、材质反射、阴影与细分隔建立层级；告警、操作、选中态、图表保留颜色。三套布局继续独立。
- 桌面按窗口高度分配场景与图表空间，内容较多的面板独立滚动。工业版核查操作固定在底部。窄窗口转为内容流。
- 同一方向内地图与设备共用场景和相机；流域推进、站区定位、设备展示、部件聚焦与结构展开均使用缓动。切换曲线不会重置镜头。
- 模型表面随鼠标出现蓝白扫描光，配合局部辉光、轻微视差和悬浮。交互参考 [Auremin](https://www.auremin.com/)，模型与着色器为本地实现。
- 图表按容器像素重绘坐标轴，文字、圆点和线宽保持正常比例。支持入场曲线生长、鼠标读数和方向键查看。

## 3D 与交互

轻盈版与沉浸版的地形使用原项目局部高程数据重采样为 256 × 256 高度场，在约 8.5 万顶点地表上重构示意河道及站区。站区包括弧形坝体、溢流结构、厂房、通风设备、升压站及旋转风机。点击电站会推进到站区，恢复视角返回流域。

轻盈版与沉浸版的水轮发电机模型包含蜗壳、曲面转轮叶片、主轴、叠片转子、24 组铜绕组、定子外壳、上导轴承、冷却管路、阀门、法兰与螺栓。支持结构展开、部件选择和旋转查看，金属材质使用环境反射。

精密工业使用独立的平面建筑沙盘及剖面模型；所有几何均在本地生成，站区形态与水轮发电机结构用于视觉与交互演示。

温度/振动切换、趋势悬浮读数、检修/复测记录、三项核查、退回复核、重新提交、关单和归档均可操作。关单后地图解除告警；刷新恢复初始状态。

所有业务数据为演示数据。地形为基于高程重构的流域示意，不是电站实际 GIS 布局；设备为程序建立的结构示意，不是厂商 CAD。滤网图片为结构示意。无生产系统连接。
