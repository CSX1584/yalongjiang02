雅砻江三方向视觉 Demo · V3

打开：双击“启动预览.command”。需要已安装 Node.js。
Release 下载包含 Three.js 依赖；从源码下载需先 npm ci。
跨平台可运行：node preview-version.mjs
开发预览：npm run dev，地址 http://127.0.0.1:5273/compare.html

历史版本：https://github.com/CSX1584/yalongjiang02/releases
V1、V2、V3 各有独立标签和 ZIP，可同时打开。

三套方向各含：3D 地图、故障诊断、关单核查。
支持连续运镜、设备悬停扫描、结构展开、曲线读数与工单操作。
全屏和短窗口按高度分配空间，长内容独立滚动。

页面使用演示数据；地形和设备为结构示意，无生产系统连接。
更多说明见 README.md。
