# 雅砻江三方向视觉 Demo · V4

三种独立页面构成，每种均包含 3D 流域地图、故障诊断、关单核查。

| 方向 | 地图 | 故障诊断 | 关单核查 |
| --- | --- | --- | --- |
| 精密工业 | 顶部仪表、左侧地形、右侧电站台账 | 大幅设备剖面、右侧判断、底部趋势 | 横向工程报告、前后对照表、页尾核查 |
| 清晰轻盈 | 待办入口、地图、横向站点卡 | 趋势证据在左、设备定位在右、底部处理步骤 | 左侧经过、中间复测记录、右侧核查 |
| 沉浸空间 | 全幅场景、站点索引、底部状态台 | 中央设备、左侧读数、右侧可展开证据 | 横向恢复结果、宽幅趋势、右侧核查与记录 |

## 本地运行

需要 Node.js。首次从仓库下载后：

```sh
npm ci
npm run dev
```

对比九个页面：http://127.0.0.1:5273/compare.html 。

交互入口：http://127.0.0.1:5273/ 。本机也可双击 `启动预览.command`，它为当前目录分配独立端口，避免历史版本误打开新版。3D 模块需要 HTTP 服务，不能直接用 file:// 打开 HTML。

- `?style=precision&page=map`：精密工业
- `?style=light&page=map`：清晰轻盈
- `?style=immersive&page=map`：沉浸空间
- `page` 可切换为 `diagnosis`、`review`

## V4 更新

- 沉浸空间改为浅色：暖白底、白色浮层、柔和接触阴影，功能和图表保留青绿色。
- 沉浸版核查页铺满可用宽度，结果与温度读数横排，趋势图横向展开，核查和作业记录独立置于右侧。窄窗口顺序排布，低高度窗口的核查列可以滚动。
- 首页/地图与设备详情直接切换，取消跨页面的飞行和画布拉伸。场景内的站点、部件聚焦和结构展开继续使用缓动。
- 精密工业使用正交投影、地形网格、设备基准网格、径向刻度、外轮廓、方形底座和图框索引。设备保持稳定，不做空闲悬浮；布局以紧凑的工程读数、分隔线和台账组织。
- 沉浸空间使用透视投影、圆形底座、柔光与轻微悬浮，操作放在场景边缘。两种方向共用设备结构，展示方式独立。

## V3 历史更新

- 黑白灰作为基础，白色卡片、材质反射、阴影与细分隔建立层级；告警、操作、选中态、图表保留颜色。三套布局继续独立。
- 桌面按窗口高度分配场景与图表空间，内容较多的面板独立滚动。工业版核查操作固定在底部。窄窗口转为内容流。
- 同一方向内地图与设备共用场景和相机；流域推进、站区定位、设备展示、部件聚焦与结构展开均使用缓动。切换曲线不会重置镜头。
- 模型表面随鼠标出现蓝白扫描光，配合局部辉光、轻微视差和悬浮。交互参考 [Auremin](https://www.auremin.com/)，模型与着色器为本地实现。
- 图表按容器像素重绘坐标轴，文字、圆点和线宽保持正常比例。支持入场曲线生长、鼠标读数和方向键查看。

## 参考的具体落点

- SSTR、Brikken：工业版以细分隔、工程编号、读数与基线对照组织内容。
- Tabella、Virya：轻盈版保持稳定横向导航，以待办、证据、核查形成工作路径。
- ON、Sobha：沉浸版让场景占据主体，站点选择带动镜头推进，操作集中在边缘。
- Zetta、ForAI：统一环境光与接触阴影，展示剖面、绕组、管路、法兰及紧固件。

## 3D 与交互

地形使用原项目局部高程数据重采样为 256 × 256 高度场，在约 8.5 万顶点地表上重构示意河道及站区。站区包括弧形坝体、溢流结构、厂房、通风设备、升压站及旋转风机。点击电站会推进到站区，恢复视角返回流域。

水轮发电机模型包含蜗壳、曲面转轮叶片、主轴、叠片转子、24 组铜绕组、定子外壳、上导轴承、冷却管路、阀门、法兰与螺栓。支持结构展开、部件选择和旋转查看，金属材质使用环境反射。

温度/振动切换、趋势悬浮读数、检修/复测记录、三项核查、退回复核、重新提交、关单和归档均可操作。关单后地图解除告警；刷新恢复初始状态。

所有业务数据为演示数据。地形为基于高程重构的流域示意，不是电站实际 GIS 布局；设备为程序建立的结构示意，不是厂商 CAD。滤网图片为结构示意。无生产系统连接。

## 版本与验证

- `main` 与 `archive-v1-20261023`：布局、模型精修前的初版。
- `refine/layout-and-3d-v2` 与 `archive-v2-20261023`：V2 布局及 3D 精修。
- `refine/responsive-motion-v3` 与 `archive-v3-20261023`：V3 高度自适应、中性色、连续运镜及悬停扫描。
- `refine/space-and-precision-v4` 与 `archive-v4-20261023`：V4 浅色沉浸、宽幅核查、正交工业视图及直接页面切换。
- `artifacts/`：初版九页预览及当时验证结果。
- `artifacts-v2/`：V2 九页预览、站区近景、结构展开及浏览器验证记录。
- `artifacts-v3/`：V3 九页预览、扫描光效果及浏览器验证记录。
- `artifacts-v4/`：V4 九页预览、宽屏与窄屏示例、展开结构、扫描光及浏览器验证记录。

浏览器验证覆盖 1024×600、1280×600、1280×720、1920×1080，以及 900×700、535×760 的窄窗口；当前 V4 共检查 54 组页面尺寸，覆盖九页；另验证直接切换、部件聚焦、结构展开、扫描光、证据展开、退回、重新提交、关单及地图告警解除。图表视口与容器像素一致，字形、线宽与圆点不随比例拉伸。

代码入口：`app.js` 管理状态和操作，`views.js` 定义三套页面结构，`scene.js` 建立三维场景，`style.css`、`v3.css` 与 `v4.css` 定义视觉和响应式布局，`charts.js` 绘制自适应曲线。
