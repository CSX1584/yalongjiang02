雅砻江三方向视觉 Demo · V2

启动：本机安装依赖后，双击“启动预览.command”。
首次从 GitHub 下载请先在本目录运行 npm ci，再运行 npm run dev。
地址：http://127.0.0.1:5273/
需要 Node.js 与支持 WebGL 2 的浏览器。请使用 HTTP 预览。

01 精密工业：顶部仪表、地图与台账、设备剖面、横向核查报告。
02 清晰轻盈：横向导航、待办工作台、趋势证据、三栏核查记录。
03 沉浸空间：全幅地图、中央设备、边缘操作、恢复结果与核查台。

每版均包含地图、故障诊断和关单核查。顶部可切换风格。
点击电站推进至站区；支持旋转、缩放、恢复视角和标签显隐。
设备支持展开结构及部件选择，趋势支持温度/振动切换。
三项核查、退回、重新提交、关单及归档均可操作。

场景与数据为演示用途。地形基于原项目局部高程重构；河道、站区布局与设备结构均为示意，非真实 GIS 或厂商 CAD。没有生产接口。刷新恢复初始演示状态。
