雅砻江 三方向视觉 Demo

启动：双击“启动预览.command”，或在本目录执行 npm run dev。
地址：http://127.0.0.1:5273/
需要本机 Node.js；依赖已包含，无需联网加载字体、模型或脚本。

01 精密工业：硬朗网格、纸白表面、橙色异常、工程剖面。
02 清晰轻盈：侧边导航、白色卡片、柔和地形、绿色操作。
03 沉浸空间：全幅深色地图、悬浮信息、暖金色定位、空间优先。

每版包含流域地图、故障诊断、关单核查。
顶部切换风格，导航切换页面。URL 的 style 和 page 参数可直接定位。

可操作项：
- 地图拖动旋转、滚轮缩放、缩放按钮、恢复视角、隐藏标签。
- 选电站联动右侧信息，官地异常进入故障诊断。
- 设备结构展开、部件选择、温度与振动曲线切换、图表悬浮读数。
- 检修记录、复测记录、核查勾选、关单、归档及退回复核。
- 关单后地图解除告警；刷新恢复初始演示状态。

场景与数据为演示用途。地形是程序生成的流域示意，设备为水轮发电机结构示意，均非实测地理或厂商模型。滤网记录采用结构示意图。不会向任何生产系统提交操作。

源码：index.html、app.js、scene.js、style.css、server.mjs。
artifacts 目录包含九个页面的浏览器预览。
